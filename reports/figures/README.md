# Рисунки из числовых агрегатов

[T19 bundle](t19/manifest.json) содержит пять рисунков в PNG/SVG и таблицы,
построенные из [публичного агрегата](../experiments/t19/aggregates.json).
[Происхождение и offline пересборка](../experiments/t19/README.md).

E1/E3/E4/E5 прошли на синтетике; E2 не выполнялся, общий study incomplete.
Нулевые E5 разности не доказывают реальное hiring quality. E3 показывает
верхние границы HTTP-простоя; E5 latency — один проход на каждую из12 групп.
Графиков человеческого времени или обещанного ускорения нет.

Для публикации используются только сохранённые агрегаты; построение этих
рисунков не выполняет обучения, model inference или повторного test read.
