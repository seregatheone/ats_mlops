# Готовность дипломной работы

Тема: **«Автоматизация жизненного цикла воспроизводимого машинного обучения в интеллектуальных системах подбора персонала»**.

Инженерная реализация и демонстрация подтверждены. Формальная программа исследований остаётся **incomplete**, поскольку человеческий эксперимент E2 ещё не выполнен.

- **T18:** приёмка пройдена по всем восьми сценариям S1–S8. Свидетельства и границы проверки описаны в [приёмке](acceptance.md).
- **T19:** E1, E3, E4 и E5 имеют статус `passed`; E2 — `not_run`, **0/5 настоящих человеческих пар**. Числа, раздельный учёт кампаний и ограничения приведены в [результатах](results.md); объём измерений закреплён [протоколом](experiment-protocol.md).
- **Demo003:** фактически пройдены все 16 этапов, выполнены два заранее назначенных fit A/B без HPO; финальный snapshot собственного Registry содержит две версии. Пройдены четыре T11 gate, четыре T12 release check, release A/B, rollback и 18 проверок recovery с двумя реальными process-exit checkpoints. Основание — [summary](../reports/demo/t20/summary.json) и [manifest](../reports/demo/t20/manifest.json).

Исполняемый source demo003 — `b3a250a6c8a0015e6b62af3fd42171c5178ad3ef`; SHA256 operator helper — `2f199b56351b598d145931dbc21db8edb7090743d5140b5df63a6b09ef944305`. Это отдельная синтетическая демонстрация по [инструкции](demo.md), без E5 read и без новых формальных измерений.

Остановленные demo001 и demo002 сохранены отдельно: оба завершились ошибкой на этапе data до обучения, с **0 fit** и успешным scoped cleanup. Их результаты не объединены с 16 успешными этапами demo003. Число **150** в summary означает subprocess-записи оператора трёх demo-запусков; внешние root-диагностики, CI и формальные серии в этот счётчик не входят.

Синтетические результаты не устанавливают качество реального найма. В E5 преимущества модели по качеству не наблюдалось, а измеренная latency модели выше Jaccard baseline. Локальный отказ `unready_container` потребовал около 64 секунд на восстановление. Эти ограничения сохраняются в выводах; таблицы находятся в [результатах](results.md).

До завершения работы остаются подлинные человеческие наблюдения E2 по протоколу и итоговое оформление текста по фактическим требованиям вуза: титульный лист, библиография, нумерация и ссылки на таблицы и рисунки. Реквизиты кафедры и руководителя должны соответствовать официальным данным. Основа текста — [черновик диплома](diploma-draft.md).
