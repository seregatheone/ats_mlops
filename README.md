# ATS MLOps

Исследовательский проект по теме «Автоматизация жизненного цикла воспроизводимого машинного обучения в интеллектуальных системах подбора персонала».

Планируемый результат — локальный стенд сопровождения модели ранжирования резюме: версии данных, проверки, обучение, регистрация экспериментов, управляемый выпуск, мониторинг, переобучение и откат.

Реализация и экспериментальные результаты пока отсутствуют. План работ и критерии завершения будут добавлены через задачи проекта и pull requests.
