# ATS MLOps

Исследовательский проект по теме «Автоматизация жизненного цикла воспроизводимого машинного обучения в интеллектуальных системах подбора персонала».

Реализован локальный стенд сопровождения модели ранжирования резюме: версии данных, проверки, обучение, регистрация экспериментов, управляемый выпуск, мониторинг, переобучение и откат.

Инженерная приёмка T18 прошла восемь сценариев на синтетических данных.
Формальные E1/E3/E4/E5 завершены и опубликованы отдельно в T19. E2 остаётся
`not_run`: пяти человеческих manual/auto пар нет, общий план E1–E5 incomplete.

Для нового демонстрационного стенда bootstrap принимает отдельные project и
сохраняемый image-prefix: это устраняет скрытую зависимость от общих локальных
build tags. Прежние defaults сохранены; пример использует собственные state,
credentials, порты и release alias. Полный clean-copy demo на source
`b3a250a6c8a0015e6b62af3fd42171c5178ad3ef` прошёл 16 этапов: два фиксированных
обучения, 0 HPO, четыре T11/T12 пакета, выпуск/откат и 18 recovery checks.
Финальный отдельный Registry содержит две новые версии. Два прежних data
failure с 0 fit сохранены отдельно. [Публичная сводка](reports/demo/t20/summary.json)
и [manifest](reports/demo/t20/manifest.json) содержат только статусы, счётчики
и SHA provenance; полный private граф не публикуется.

Счётчик 150 в сводке — записи subprocess команд оператора по трём demo runs.
Он исключает root diagnostics, CI и формальные серии; это не измерение
человеческих действий или ускорения E2. Демонстрационные fits не входят в T19.
