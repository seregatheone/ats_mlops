# ATS MLOps

Исследовательский проект по теме «Автоматизация жизненного цикла воспроизводимого машинного обучения в интеллектуальных системах подбора персонала».

Реализован локальный стенд сопровождения модели ранжирования резюме: версии данных, проверки, обучение, регистрация экспериментов, управляемый выпуск, мониторинг, переобучение и откат.

Инженерная приёмка T18 прошла восемь сценариев на синтетических данных. Формальные эксперименты E1–E5 выполняются отдельно по зафиксированному протоколу; их результаты в пакет приёмки не входят.
